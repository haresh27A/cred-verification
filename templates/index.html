Application Workflow & Output Specifications

1

Input Excel / CSV Requirements

Supports files with columns like PENDINGCPNAME, FIRSTNAME, LASTNAME, NPI, Credental, STATE, CITY, ADDRESS, and PHONE.

2

Automated Verification Rules

  • NPI Validation: Validates existing 10-digit NPIs against NPPES Registry API, detecting deactivated or mismatched Org NPIs (NPI-2).
  • NPI 1 Search: Finds individual provider NPI (NPI-1) using name and location fallback logic.
  • Credential Extraction: Searches web sources and embedded text for credentials (MD, DO, APRN-CNP, FNP-BC, PA-C, LCSW, etc.).
3

Professional Excel Output (.XLSX)

The exported Excel file includes:

  • Dark Navy Header styling (#1E293B) with bold white text.
  • Red cell highlighting (#FCE8E6 fill + #991B1B bold font) for invalid or mismatched NPIs.
  • Clickable hyperlinks for Url and NPI 1 Url.
  • Auto-adjusted column widths and gridlines.
